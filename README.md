# CG Exam Trainer（CGクリエイター検定ベーシック 対策アプリ）

CGクリエイター検定ベーシックの合格をめざす生徒のために作った、練習用のWebアプリです。

- 問題セット：20回分（4択・解説つき）
- 作り：React + Vite
- 用途：生徒の受験対策として無償で作成

A practice web app for the CG Creator Certification (Basic) exam, made for a student. 20 question sets with explanations. Built with React + Vite.

## 動かし方 / Run locally
```
npm install
npm run dev
```

Made by EduVest Technologies. For learning purposes.
